\# FocusVision AI 👀🔥



\## 📌 Overview

FocusVision is an AI-based system that tracks user focus using webcam and provides real-time feedback.



\## 🚀 Features

\- Real-time face \& eye detection

\- Focus score calculation

\- Live dashboard

\- Alert system when distracted



\## 🛠️ Technologies Used

\- Python

\- OpenCV

\- Flask

\- HTML, CSS, JavaScript



\## ▶️ How to Run

1\. Run server:

&#x20;  python server.py



2\. Run AI:

&#x20;  python main.py



3\. Open index.html in browser
